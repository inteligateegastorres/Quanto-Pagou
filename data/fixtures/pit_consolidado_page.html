Download de Dados

O painel Download de Dados do Portal Informação para Todos tem como objetivo disponibilizar dados brutos em formato aberto para download. Isso significa que cidadãos e entidades da sociedade civil poderão acessar os dados públicos captados das públicas municipais do Estado Paraná e, com eles, desenvolver as análises desejadas.

Para baixar os dados clique no ano desejado, o arquivo contém os dados de todos os munucípios. Além dos arquivos com temas como Licitações, Contratos, Despesas, dentre outros está disponível também o arquivo de relacionamentos que contém os vínculos entre os temas.

Os arquivos para Download de Dados são gerados uma vez por semana, abrangendo dados de remessas fechadas e estão sujeitos a mudanças (acréscimos, alterações ou exclusões), tanto de seus registros quanto de sua forma, por iniciativa dos próprios jurisdicionados ou necessidades e determinações do Tribunal de Contas do Estado do Paraná.

As informações utilizadas para a geração dos arquivos de Download de Dados são declaradas pelas entidades jurisdicionadas e são de sua inteira responsabilidade.
